# TVStation

מערכת לניהול תצוגות דיגיטליות (digital signage) בטלוויזיות במסדרונות בתי ספר.
כל "אתר" הוא עמוד סטטי שמציג קרוסלת תמונות, טקסט רץ (טיקר) שניתן לעריכה, וקוד QR קבוע
בפינה הימנית התחתונה. העמוד בודק כל 15 דקות אם פורסמה גרסה חדשה ומתרענן אוטומטית -
כך שהתוכן מתעדכן בטלוויזיה בלי שאף אחד צריך לגעת בה.

## מבנה הפרויקט

```
sites-data/<slug>.json     קונפיג לכל אתר תצוגה (שם, כיוון, קרוסלה, טיקר, QR)
assets/<slug>/images/      התמונות שהועלו לכל אתר
generator/                 Eleventy - בונה את ה-HTML הסטטי מתוך sites-data
admin/                     פאנל ניהול מקומי (Node/Express) לעריכת תוכן
dist/                      פלט הבנייה - זה מה שמתפרסם בפועל (לא נשמר ב-git)
```

## התקנה

דרוש [Node.js](https://nodejs.org/) (גרסה 18 ומעלה).

```bash
npm install
```

## עבודה יומיומית - עריכת תוכן

הרץ את פאנל הניהול:

```bash
npm run admin
```

ופתח בדפדפן: http://localhost:4000

בפאנל אפשר, לכל אתר:
- לקבוע שם, כיוון מסך (אופקי/אנכי) וכתובת QR.
- להעלות/למחוק/לסדר מחדש תמונות קרוסלה.
- לערוך את שורות הטיקר (שורה אחת בכל שורת טקסט).
- ללחוץ **"בנה בלבד"** כדי לייצר את קבצי ה-`dist/` מקומית לבדיקה.
- ללחוץ **"בנה ופרסם"** כדי לבנות ואז לשלוח (`git commit` + `git push`) לריפו -
  זה השלב שבפועל מעדכן את מה שהטלוויזיות רואות.

### כיוון מסך אנכי (Portrait)

אם הטלוויזיה מוצבת לרוחב אך לא תומכת בסיבוב תמונה native, סמן את התיבה
"הטלוויזיה לא מסתובבת לבד - סובב את התוכן ב-CSS" בהגדרות האתר - העמוד יסובב
את עצמו ב-90 מעלות וימלא את המסך נכון.

## בנייה ידנית (בלי הפאנל)

```bash
npm run build      # בונה פעם אחת ל-dist/
npm run watch       # בונה ומריץ שרת פיתוח מקומי עם רענון חי
```

## פרסום והתקנה חד-פעמית (Netlify + GitHub)

שלבים חד-פעמיים שצריך לבצע בעצמך (דורשים את חשבונות ה-GitHub/Netlify שלך):

1. `git init` ואז `git add -A && git commit -m "Initial commit"` בתיקיית הפרויקט.
2. צור ריפו חדש וריק ב-GitHub, וחבר אותו: `git remote add origin <URL> && git push -u origin main`.
3. ב-[Netlify](https://app.netlify.com/) - "Add new site" -> "Import an existing project" -> בחר את הריפו.
   - Build command: `npm run build`
   - Publish directory: `dist`
4. אחרי הדיפלוי הראשון, כל אתר יהיה זמין בכתובת:
   `https://<your-site>.netlify.app/<slug>/`

מכאן והלאה, כל לחיצה על "בנה ופרסם" בפאנל הניהול (`npm run admin`) תפעיל דיפלוי אוטומטי ב-Netlify.

## הצבת התוכן על הטלוויזיה

בכל טלוויזיה חכמה, פתח את הדפדפן המובנה שלה בכתובת האתר המתאימה
(`https://<your-site>.netlify.app/<slug>/`) והפעל מצב מסך מלא, לפי מה שהדפדפן של
אותה טלוויזיה תומך בו. העמוד יבדוק כל 15 דקות אם התוכן התעדכן, ובנוסף מתרענן
מעצמו כל 24 שעות כרשת ביטחון.

## הוספת אתר/מסך חדש

הכי פשוט - דרך הפאנל (`npm run admin` -> "+ אתר חדש"). אפשר גם ידנית: הוסף קובץ
JSON תחת `sites-data/` (לפי הסכימה למעלה) וצור תיקיית תמונות תואמת תחת
`assets/<slug>/images/`.
